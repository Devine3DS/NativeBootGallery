FROM THE GALLERY TO YOUR CONSOLE

Choose your boot path

For RGH/JTAG consoles running dashboard 17559. HDD and NAND files are different; download the version that matches your setup.

01 / HDD

Keep your animation on the hard drive

Use the HDD XEX download. Once the remap is installed, changing themes only means replacing one file.

  1. Back up your working NAND, CPU key, original animation and image-builder settings.
  2. Get remap_bootanim_17559.bin from the Xbox360BootAnimationCreator release.
  3. Put the patch in xeBuild/17559/bin/ within your image-builder setup.
  4. Add -a remap_bootanim_17559 to your normal xeBuild build arguments. Keep the correct board, NAND and hack settings for your own console.
  5. Complete any required RGH3 conversion and verify the finished NAND image before flashing it through your established workflow.
  6. Rename your downloaded HDD file to bootanim.xex and copy it to the internal HDD root: Hdd:\bootanim.xex (also shown as Hdd1:\bootanim.xex).

Already using this remap? Replace the HDD file and reboot. A new NAND build is not needed to switch animations.

02 / NAND

Include it in your NAND image

Use the NAND XEX download and rebuild the flash filesystem through your usual image builder.

  1. Back up your working NAND, CPU key and builder configuration. Work in a copy of the builder setup.
  2. Rename your NAND download to bootanim.xex and place it at xeBuild/17559/bootanim.xex.
  3. Open the firmware INI your build actually uses (for example _glitch2.ini). In [flashfs], replace only the CRC-32 in the bootanim.xex entry. Each card’s File details shows the correct NAND CRC-32.
  4. Build using your console’s verified settings, without the HDD-remap argument. Complete the required RGH3 steps.
  5. Check that the log uses your replacement file and its matching CRC. Verify the final image, then flash it through your established workflow.
  6. Restore your builder’s original file and INI afterwards, so another build does not accidentally inherit the theme.

If the kernel still redirects to the HDD, replacing the NAND animation will not select it. Choose one boot path and use its matching file.

Download names, testing and troubleshooting

The website gives each download a unique name to keep it identifiable on your PC. Rename the selected file to bootanim.xex before installing. Never install both targets interchangeably.

Still images were captured at approximately 5.8 seconds from each actual export in the native renderer through Xenia. Motion previews are native-renderer recordings. Emulator output can differ from console hardware. Blue Nexus / Deep Orbit has a successful console test reported by a user; the other custom variants still need hardware testing.

If the stock animation appears, check the active boot path, filename, export target, firmware INI and NAND build log. The remap targets the internal HDD root; USB drives and subfolders are not its documented target. Do not assume it falls back to the NAND when the HDD file is absent.

The project does not build or flash a NAND for you. Use the correct workflow for your board and NAND type. See the linked installation guide for J-Runner’s custom-command and RGH3 conversion details.
